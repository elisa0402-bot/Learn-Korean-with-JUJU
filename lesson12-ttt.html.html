TEACH · ① -(으)ㄹ 테니

-(으)ㄹ 테니(까): 내가 할게요 / 아마 그럴 거예요-(으)ㄹ 테니(까): my intention, or a strong guess-(으)ㄹ 테니(까) : mon intention, ou une forte supposition

① 내가 할 일을 말하고, 상대방에게 부탁해요.① I say what I will do, then ask you to do something.① Je dis ce que je vais faire, puis je vous demande quelque chose.

오늘은 제가 점심을 살 테니 민수 씨는 커피를 사 주세요.Lunch is on me today, so buy the coffee, Minsu.Le déjeuner est pour moi, Minsu, prends les cafés.

제가 자리를 잡을 테니까 먼저 주문하세요.I will get a table, so order first.Je garde une table, commandez d’abord.

② 강하게 추측하고, 조언이나 제안을 해요.② I make a strong guess, then suggest something.② Je fais une forte supposition, puis je propose quelque chose.

주말에는 사람이 많을 테니 예약하고 갑시다.There will be many people on the weekend, so let’s book.Il y aura du monde le week-end, réservons.

지금은 길이 막힐 테니 지하철로 가요.The roads will be jammed now, so let’s take the subway.Les routes seront bouchées, prenons le métro.

형태 · Form · Forme예
동사 (받침 O)V + -을 테니(까)먹다 → 먹을 테니
잡다 → 잡을 테니
동사 (받침 X)V + -ㄹ 테니(까)오다 → 올 테니
사다 → 살 테니
ㄹ 받침ㄹ 탈락 없이살다 → 살 테니
들다 → 들 테니
추측: 형용사A + -(으)ㄹ 테니춥다 → 추울 테니
많다 → 많을 테니
추측: 명사N + 일 테니학생 → 학생일 테니
추측: 과거V/A + -았/었을 테니도착하다 → 도착했을 테니

-(으)ㄹ 테니 = -(으)ㄹ 테니까. 뜻이 같아요.-(으)ㄹ 테니 and -(으)ㄹ 테니까 mean the same.-(으)ㄹ 테니 et -(으)ㄹ 테니까 ont le même sens.

자주 틀리는 부분Common mistakesErreurs fréquentes

1

뒤 문장은 명령 · 청유 · 요청이에요.The second part is a command, a suggestion or a request.La 2e partie est un ordre, une proposition ou une demande.

사람이 많을 테니 가지 말았어요 ✗ → 사람이 많을 테니 가지 맙시다. ✓
TEST 1 · 3번, 14번 관련
2

의지(①)일 때는 앞 = 나(저), 뒤 = 상대방이에요.For intention: first part = I, second part = you.Pour l’intention : 1re partie = moi, 2e partie = vous.

제가 예약할 테니까 제가 전화할게요 ✗ → 제가 예약할 테니까 민수 씨는 시간만 알려 주세요. ✓
TEST 1 · 16번 관련
3

이미 끝난 일에는 쓰지 않아요.Not for things that already happened.Pas pour des faits déjà passés.

어제 사람이 많을 테니 다른 식당에 갔어요 ✗ → 어제 사람이 많아서 다른 식당에 갔어요. ✓

TEACH · ② -도록

-도록: 그렇게 되게 / 그 정도로-도록: so that… / to the point that…-도록 : pour que… / au point de…

① 뒤 행동의 목적을 말해요.① It gives the goal of the action that follows.① Il indique le but de l’action qui suit.

실수하지 않도록 연습을 많이 했어요.I practiced a lot so as not to make mistakes.Je me suis beaucoup entraîné(e) pour ne pas faire d'erreurs.

손님이 많이 찾아오도록 홍보를 하고 있어요.They are advertising so that many customers come.Ils font de la publicité pour attirer beaucoup de clients.

② 정도나 한계를 말해요.② It shows the extent or limit.② Il exprime le degré ou la limite.

배꼽이 빠지도록 웃었어요.I laughed my head off.J’ai ri aux éclats.

새벽 두 시가 넘도록 숙제를 했어요.I did homework until past two in the morning.J'ai fait mes devoirs jusqu'à plus de deux heures du matin.

형태 · Form · Forme예
동사V + -도록먹다 → 먹도록
오다 → 오도록
부정V + -지 않도록늦다 → 늦지 않도록
가능V + -(으)ㄹ 수 있도록먹다 → 먹을 수 있도록
부드러운 명령V + -도록 하세요늦지 않도록 하세요.

형용사에는 -도록 대신 -게를 써요: 깨끗하도록 ✗ → 깨끗하게 ✓With adjectives use -게, not -도록: 깨끗하게 ✓Avec les adjectifs, utilisez -게 : 깨끗하게 ✓
